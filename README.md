## 🚀 Local Development Setup

The Kyte Studios website is designed to be lightweight, modern, and lightning-fast. It leverages modern Tailwind CSS and GSAP animations loaded securely.

To run the landing page locally:

### Prerequisites
You need a simple HTTP server to serve the static assets (required to allow custom media and video elements to load and scale perfectly without CORS issues).

### Running the Project
Choose any of the following methods:

#### Method A: Using VS Code (Recommended)
1. Open the `Website` folder in VS Code.
2. Install the **Live Server** extension.
3. Click the **Go Live** button in the bottom right corner of your status bar.

#### Method B: Using Python
Run this command from your terminal inside the `Website` directory:
```bash
python3 -m http.server 3000
```
Then open your browser and navigate to `http://localhost:3000`.

#### Method C: Using Node/NPM (`serve`)
If you have Node installed, you can use the static server package:
```bash
npx serve .
```
